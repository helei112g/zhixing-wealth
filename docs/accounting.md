# 计算与数据来源

买入复盘展示截至当前累计收益、收益率、剩余份额市值和关联卖出；卖出复盘展示所选多笔买入的成本分摊、净回款、含息费税盈利与 XIRR。单笔盈利使用实际买入成本（含费税）、指定卖出回款和该批次应得净分红，与1周/1月/3月的市场走势观察分开。

- 部分卖出按所选批次内部份额比例分摊成本和权益；同一份额不能卖两次。历史编辑如使后续关联卖出失效，会拒绝整个变更。旧备份中无关联的卖出兼容按FIFO推导并明确提示，重新更正时须确认具体批次。
- 已平仓停止证券价格估值；未到账回款或分红标记“待结清”，外币应收仍按当前估值汇率。到账后锁定既有现金流。后补实际分红、税费和历史更正仍会重算。
- 红利再投建立有经济成本的独立批次，个人新增本金为0。不能把再投成本设为0，否则会重复计利润。
- 后补费用或股息税可在录入费用/税费时关联原买入、卖出或分红。未关联的独立费税只计组合盈利，单笔会明确提示未分摊；不会自动扣在后来新买批次上。
- XIRR按[Microsoft官方定义](https://support.microsoft.com/en-us/excel/functions/xirr-function)使用实际现金日期与365天，买入及关联费用为负、卖出和分红回收为正。多批次按各自付款日处理；同日、无解、多解或缺少估值时不显示年化率。求解在 `log(1+r) ∈ [-30,30]` 内用导数临界点隔离，覆盖切点根；超范围保留为未知。期初份额只能从记账起算。

组合的成本归因仍用移动加权平均，逐笔分析用指定批次成本；已实现/未实现分类可不同，总盈利一致（未分摊费用、未知企业行动等会明确提示）。


## 自动分红待核对

更新数据时同时拉取公开分红公告，启动补更和23:30更新也适用。在标的详情的“分红公告与记录”中核对金额、税费与到账日，选择现金分红或红利再投，预览后确认。公告缓存与忽略操作均不改变资产和收益；确认才生成可更正的普通分红流水。已确认的公告、同除息日已有手工分红不会重复入账。总览显示待确认数量和预计金额，“资金与流水”集中处理所有标的分红。补录、更正或取消交易后，所有公告权益按登记日账本重算；已确认分红如受影响，显示原金额、重算额和差额，重新确认时原位更正同一流水并保留审计，不静默改写实收金额。红利再投确认份额仍须本人按交割单核对；变更再投后会继续重算后续分红权益。

- A股场内ETF、LOF、场外基金：天天基金分红送配表，每10份分红除以10；登记日账本份额估算权益，场外基金只计已确认份额。
- A股股票：东方财富已实施分配表，每10股现金除以10；该接口不提供派息日，需要补充实际到账日期，不能拿公告日替代。
- 港股场内股票与ETF：03110、03116、03419优先Global X官方上市类别分派表，保留每份币种、除息日、派息日和收入/资本来源比例；通用港股优先东方财富明确币种的现金方案，缺覆盖时使用Yahoo现金分派参考。03110官方表当前展示20条历史，不宣称成立以来完整；02800也可使用后备分派源。过户截止期间不当作登记日。
- 美股场内股票与ETF：美元记账、按代码识别，`BRK.B`规范为`BRK-B`。Nasdaq普通股票Cash行优先，包含实际每股金额、登记日和派息日（旧记录允许缺失）；ETF等缺覆盖时使用Yahoo参考。美股与港股均按**除息日前**成交日账本份额估算权益，不按美股登记日收盘错误分配。
- 后备源限制：Yahoo每股分派可能舍入，且不提供派息日，必须在确认时按公告补充核对；同一除息日按优先来源选用，不跨来源累加。实物分配、不同派息币种、先派息后除息的特殊安排不会自动确认。

公开数据不能知道个人税费、实际到账与再投确认份额。税额默认未核对，估算金额允许修改；没有完整历史持仓时也须以交割单为准。分红公告保留来源、原始单位和抓取时间，来源失败保留已有缓存并在更新记录提示，不把失败当作没有分红。

## 港美股行情口径

美股通过Yahoo日线，按交易所时区归属日期，排除当前交易日未结束的数据。源的Close已按后续拆分调整，适配器取得起点至今全部拆分，并逆向恢复历史名义价格后才写入`raw`；Adjusted Close仅作复盘参考，不作为真实市值或已核验全收益序列。已公开的拆分只缓存为待办，存在拆分前旧持仓而尚未确认时不输出误导的估值与年化；核对并保存现有拆分记录后重算数量。

公开源按标的短暂缓存；Yahoo出现429后进入10分钟冷却，不反复请求；其他源失败保留旧数据，不把失败当作零分红。各源覆盖和精度不同，交割单、发行方公告仍是实际到账的核对依据。


## 数据完整性

未核对分红仍按当前已录金额计入暂计收益，核对状态本身不改变金额。缺行情、汇率、拆分确认或历史投入时，未知值保留为 null，界面给出待办。

税额已核对用于区分确认为零和税额未知；除息日已核对确认收益归属日，不是到账日。已平仓停止证券价格估值，但后补分红、关联补税和历史更正仍会重新计算。

按期收益的暂估原因可展开查看影响日期。已配置的沪深/港股休市日历只在已验证年份使用，其他年份或市场不假定没有数据就是休市。行情、公告和日历覆盖需要持续维护。
