# 知行财富统一交互与统计设计规范

Leo · 2026.10.28

本文是跨模块交互的统一约定。新功能必须先复用这里定义的公共能力，再扩展业务数据；不得各自创建提醒中心、消息横幅或独立通知权限。

## 系统提醒中心

分红 needs_review 并列提供“保留实际到账金额并完成核对”和原重算入口。保留操作先展示原税前/税额/净额、费用、日期、锁定汇率及再投事实，二次明确提交核对结论；返回或关闭不写入。候选携带原 revision，冲突展示错误并提供重新读取。保留成功后待办和对应系统通知退出，原流水保持原样。

### 入口与职责

- 唯一中心位于侧边栏「全局 → 提醒中心」，不属于资产总览或某个组合。组合选择不限制提醒范围。
- 全系统只保留一个顶部提醒栏，显示数量和简短摘要，进入同一中心；中心页面不重复显示这个入口。模块内原有专门的待办列表、分红通知栏、重复到期列表退役。
- 提醒中心只汇总事实、展示状态、定位原功能。资产到期提醒没有「已处理」按钮；到期不等于已经还款，通知不修改金额。交易核对、分红确认、同步重试继续由原业务接口执行并校验。
- 与当前字段或交易直接相关的校验、数据缺失说明仍可原位展示，不另建消息收件箱。
- macOS 通知权限、开关、状态、测试入口统一位于全局设置。通知使用知行财富品牌图标、默认隐藏账户名称与金额；系统受理和实际显示分别验收。

### 数据契约与扩展方式

`GET /api/reminders` 是页面唯一汇总入口，`backend/reminders.py` 的 `ReminderService` 负责聚合与去重。后续功能需在该文件的 provider 注册表增加适配器，不能另建中心接口和页面。业务事实保留在原表中，读取提醒不新增账务、不确认业务完成。

每条记录包含：

| 字段 | 约定 |
|---|---|
| `id` | 来源命名空间加稳定业务键；不能使用列表序号或本次查询时间 |
| `source`、`kind` | 来源分类与具体业务种类；新增来源同步维护中心筛选项 |
| `title`、`detail` | 简短清楚的事项与必要上下文；同步错误展示用户可理解的原因 |
| `date`、`days` | 业务日期与距离到期天数；不是到期事项时 `days=null` |
| `amount`、`currency` | 可核对的金额、币种；未知用 null，不补零 |
| `severity` | attention / today / upcoming，待核对和今天到期优先 |
| `action` | 可选业务导航描述，不直接执行写入；包含精确组合、标的、事件作用域 |

现有 provider：

- 还款、保费、续保：投影今天至未来35天，含第35天；过期移出。应收款不生成收款计划。每期由业务ID与期次标识，不重复展示手工旧计划。
- 分红：所有未归档组合的 pending / needs_review 候选；确认或忽略后移出。未确认候选不计入收入；同一事件不再重复产生税额核对事项。
- 交易核对：分红税费、送转/拆股等待核对项，统一从顶部“查看提醒”进入中心，再打开对应组合原表单，不跨组合串数据。组合和标的页面不重复铺设独立待办区。
- 送转流水在两处共享交易表显示前后数量、倍数与参与批次数，金额列显示总成本不变；详情列出除权日前剩余批次。买入行保留原数量，同时显示当前剩余份额。历史补录预览显示受影响送转的前后结果，确认记录保留，批次从当前历史重算；无持仓明确显示不调整份额。
- 送转确认保留公告关联，日期或倍数冲突回到原流水核对；旧登记日误填作为核对候选，不能据此自动改账或再次新增。表单并列说明登记日和除权日，显式选用公告值后仍需预览与原revision提交。
- 当前组合的估值说明（含缺失原因、估值日期与最近完整日）折叠在同一个顶部提醒栏，随组合及所选截止日期更新；属于上下文说明，不重复计入全局待办数量。只有估值说明时仍显示提醒栏，不提供通向空提醒中心的按钮。
- 同步：最近20次任务中同一来源项取最新状态，成功后旧错误消失；任务更新不依赖财务 revision，因此不能只按账本版本缓存这些事项。
- 系统：通知已启用但发生错误时，展示全局设置入口。

账务 provider 可按 revision + 日期缓存；缓存不能覆盖实时同步任务和通知状态。响应包括 `count`、`today`（当天到期数）、`revision`、`as_of`。页面每45秒、窗口聚焦及账本/同步状态变化后刷新；旧异步响应不得覆盖新结果。

### 原生通知复用

分红原生通知与中心共用候选 provider；稳定 `reminder_id` 用于定位，实质内容指纹用于发送去重。重复抓取时间不产生新通知，候选变化可重新提醒。还款/保费仍提前登记未来366天，提前7天、1天及当天09:00（上海时区）提醒，页面保持35天窗口。

所有原生通知点击统一打开 `?reminders=1&focus=<reminder_id>`；若业务已解决或到期，进入中心正常空态，不重新造出已失效事项。旧 `?family=reminders` 进入全局中心；旧 `?dividend=<portfolio_id>` 保留兼容。冷启动必须校验本机环境、端口、数据目录身份，不能连接到另一账本。

新增通知种类的验收至少覆盖：稳定ID与去重、原事实变化后消失、跨组合隔离、未知金额、导航目标、无写入副作用，以及需要原生通知时的真实显示和点击。

## 资产总览录入与收入明细

现金、固定资产、手工理财、应收款均使用「类别 → 币种 → 名称/渠道 → 金额 → 金额日期」。日期默认今天、不可晚于今天。保存是该日期的金额记录，不抹掉后来的余额；补录旧日期后，当前余额仍取最新有效日期。新增与编辑复用同一表单，编辑时类别和币种置灰。

页面仅保留顶部「新增记录」。进入台账分类、保险或收入页时预选对应类别；分类列表不再增加第二个新增按钮。「关联投资组合」入口仅在资产总览顶部展示，台账、趋势、保险和收入页不展示。关联组合仍只支持关联/解除，金额和来源日期由组合提供，资产端不可反向写入。

台账采用左侧分类与项目、右侧明细，默认全部项目，不提供搜索框。现金、固定资产、投资理财、应收款、负债、保险均可直接分类查看；负债和应收款不再占用独立页签。窄屏用分类按钮和项目列表进入详情，保留同一更新流程。旧负债、应收款链接映射到相应台账分类。

手工资产（含应收款）列表和详情统一使用「更新信息」，负债使用「更新负债」。详情保留余额历史，移除内嵌更新余额表单和顶部返回列表按钮；通过左侧分类/项目导航切换。统一编辑表单核对金额日期、完整余额和资料，类别与币种仍不可改。余额更正追加快照，不重复创建项目，不覆盖后续日期；未改动的还款/保险规则保持原值。相同日期后写记录生效，旧值保留；补录早于首笔日期时必须明确预览提前起始日期，仅现金、固定资产、手工理财、应收款支持。新增表单命中同类同币种同名项目时，提供显式转入该项目更新入口，保留已填金额与日期，不自动合并。

每个资产分类顶部显示后端分类总金额、项目数与占总资产比例；金额未知时不补零，展示已知金额和待补说明。关联项目详情使用投影 value 字段，查看组合后可返回原分类与项目；解除关联单独放在管理区并用红色标识，仍须预览确认。

负债列表和详情统一使用「更新负债」完整表单，保留余额历史，不提供快捷余额编辑器。负债分类顶部显示总负债、本自然月计划应还、可用现金覆盖倍数。本月应还按当前付款规则计算整月，包含本月已过日期，不代表实付或尚欠；不减记债务与现金。生成规则金额已经是实际持有/承担金额，不再次乘持有比例。现金覆盖＝可用现金÷本月应还，无计划、缺汇率时保留未知并展示已知部分；本月为零时显示无需还款，不显示无限倍。

收入顶部展示所选年份已记录累计金额、录入月份数、四类金额及各自占比，由后端 summary 统一提供。年度组成在一条横向分段条中按比例展示，颜色与月度柱图一致；图例保留各类金额和占比，不为零或未知占比绘制占位份额。无记录时累计未知；有缺失汇率时累计和全部占比未知，同时显示已知部分；零累计不计算占比。收入按工资、租金、公积金、自定义四类使用稳定颜色的堆叠柱状图。表格为月度汇总，点击月份或柱形打开当月侧栏，明细编辑沿用收入表单，保存后回到该月并刷新。明细不常驻铺在页面。未录入月份显示「未记录」，缺汇率不画成零；金额不重复加入现金或总资产。

## 资产总览统计口径

摘要在一个面板中用六根同尺度柱形展示总资产、总负债、流动现金、固定资产、投资理财、应收款。蓝色表示本期保留部分，红色表示相对上期增加，绿色虚线区段表示相对上期减少；减少区段不计入本期金额。虚线标出上期金额，柱形标出当前金额、变化金额与比率。总资产包含保单现金价值；总额与分类柱不可重复相加。已记录收入以具体起止日期标注，和负债率一起保留在同一面板下方。负债率复用期末总负债÷总资产；缺少金额或总资产不大于零时不计算，净资产在资产组成图中展示，不展示净资产趋势曲线。

- 默认按月：当月1日到月末，未结束月份截至今天，余额与上月末比较。
- 按年：当年1月1日到12月31日，未结束年份截至今天，余额与上年末比较。
- 自定义：明确起始、结束日期，均包含，余额与起始日前一天比较。界面从第一笔记录日期起可选，不晚于今天，跨度不超过30年。
- 总览年份从最早资产或收入记录所在年起提供；月份与自定义起始日同样受第一笔日期限制。资产历史以资产的首次计入日为下限，不把借款发生日或未来还款日当成余额记录日。已有余额可延用，因此中间未更新月份不被删掉；收入年份只列存在收入的年份。
- 资产是结束日余额，不能把每日或每月余额相加。变化金额＝结束日余额−比较日余额；缺比较记录显示未知。新增、移除和份额调整计入总金额变化，scope_changed 标记并注明原因；两期金额已知且上期大于0时计算变化率。基数≤0、缺金额/汇率不计算比率。不把未知当0，不使用未来数据。
- 收入是区间内记录金额之和，不与资产相加。按记录日期归属；只有月份的历史录入默认该月末，本月默认录入当天，不按天平摊。更正取最新版本，不重复累计。外币按记录日或此前最近历史汇率换算。API 中收入基线为上一个完整自然月/自然年，自定义为之前等长区间；页面不把未结束期间的收入差称为同比。
- 收入无记录时合计未知；存在记录也仅代表已记录收入，展示录入月份数，不暗示其他月份为零或全部收入完整。
- 流动现金为可用现金余额，不含应收款及受限现金。现金可覆盖还款月数＝可用现金÷所选结束月份的计划还款额，仅作月数折算，明确不包含生活开支、保费，也不假设后续月份还款额相同。负债本金不能直接当作每月固定开支；必须有付款规则。规则/汇率缺失或现金未知则不输出月数，该月无应还则显示无计划还款，不显示无限月数。不恢复开支计划功能。

后端 `family_summary.py` 是总览期间口径唯一实现，`GET /api/family/summary` 返回区间、快照、六类金额及兼容指标、比较基线和现金覆盖估算，前端只格式化。总览和趋势分析都按相邻期末比较；API 显式同比与相邻期比较分别测试、准确命名。合成测试覆盖日期边界、闰年、零/负基数、缺汇率、范围变化及补录历史。

趋势分析默认从当前年1月1日至今天，首笔资产前不补值。使用 comparison=previous：按月比较上月末、按年比较上年末，未结束期间以所选截至日对比上一期末。灰色虚线使用右侧百分比轴，顶部显示最新期间的金额、增减和变化率，下方独立金额刻度展示每期增减，避免大额资产遮蔽小幅变化。每期明细按日期倒序，每页12期，切换指标、日期或粒度后回到第一页；图表始终保留所选区间所有期。总资产柱形按类别堆叠，单个类别按具体项目堆叠；净资产用正向资产与负向负债表示，净资产为两者之和，并用蓝色实线标出。每期保留完整组件 ID、名称、金额，缺金额不补零。变化率仅比较所选指标的项目与份额范围，不因别的类别新增项目而抑制本类别曲线。右轴留白使 0% 清晰可见；仅一个有效点时标注百分比，缺失期间断开，不连线伪造趋势。没有可比点时明确说明原因。

桑基图使用横向「各项负债 → 负债、净资产 → 总资产 → 资产类别 → 项目」布局；净资产为负或负债未知时不绘制负值流，改为独立列出债务与净资产、只拆解资产。所有带宽按金额比例绘制，不把小金额强行放大；小节点通过增加间距保证标签可读。每类超过10个明细时汇总后续项目并保留点击明细。支持金额、占总资产比例、隐藏金额三种显示；隐藏状态下图形、标签和明细不泄露数值。按节点数量和容器宽度自适应高度，禁止内部滚动与固定高度裁切；窄屏保留可点击的完整分类金额清单。

## 资产命名、组合入口与金额阅读

- 侧边栏分组为「资产分析」，下设总览、趋势分析、保险、收入，与投资组合、全局分组使用同一导航样式。总览中以「资产更新」进入原资产台账，可返回总览；页内不再重复页签。主标题显示当前子页面，API family 路径与内部 analysis/assets 键保持兼容。
- 新建、编辑组合支持可选纯文字介绍，最多10000字并保留换行；总览的「组合介绍」折叠区可阅读及打开编辑，空介绍提供填写提示。旧组合未填写按空介绍显示，读取不改写数据。
- 组合选择和创建放在「组合收益」「持仓标的」「交易记录」三页顶部同一行、靠近标题的位置；切换后停留在当前菜单，重置该组合的筛选与分页，不显示上一组合的旧结果。侧栏只保留导航，资产分析及全局页面不展示组合选择。页面导航和重载使用上次有效选择；无组合时提供创建入口，失效选择回退到可用组合，已归档组合仍可选择查看。
- 金额增减红增绿减，零值和未知值为中性色；资产绝对余额不作为涨跌着色。大数按万、亿显示两位小数，精确金额通过悬停/可访问描述或表格原值保留。台账精确金额下补数量级提示；所有输入与API仍使用完整金额。
- AI 接入遵循 `docs/ai.md`，页面新增业务能力同时补齐发现、请求契约、客户端与项目技能。

## 全局下拉选择框

- 单选下拉框统一使用 `frontend/src/select.css`：8px 圆角、浅色边框、右侧独立箭头区域，文字预留46px右内边距，避免贴边或遮挡。页面不得重新覆盖箭头和左右间距。
- 组合选择、筛选、年份、录入弹窗和交易侧栏复用这套样式。常规高度42px，紧凑筛选36px、分页34px；窄屏至少44px并使用16px文字。
- 悬停提升边框对比，聚焦显示清晰轮廓；禁用状态同时作用于字段和整个 fieldset。保留原生 select 的键盘选择、可访问名称、必填校验和系统弹出选项能力。
- 多选列表不应用单选箭头；高对比模式恢复系统外观，减少动态效果偏好下禁用过渡。此展示调整不改变 API、金额或选择值。

## 全局设置列表

- 行情与净值缓存按标的每页10条，显示总数与当前页；翻页只切换展示范围，不改变同步目标。同步全部历史覆盖全部标的。数据刷新保留当前页，页数缩小时校正页码；历史行情不因分页清理。
- 更新记录只展示最近5条，按启动时间和创建顺序倒序；默认最多保存20条（含运行中），任务保存和服务启动时执行轮转。运行中任务不被清理，异常存在超过20个运行中任务时暂时超限，启动恢复后回到20条。API为兼容仍返回最多20条，业务审计与笔记历史不参加轮转。


### 持仓与流水展示补充（2026.10.30）
