## 重新生成

在已安装开发依赖的源码目录执行：

```sh
npm --prefix frontend run build
.venv/bin/python scripts/showcase.py
```

脚本在源码之外的 `local/work/showcase/` 下新建随机临时目录，固定 test 环境和 `127.0.0.1:8876`，关闭同步；不接受已有账本路径，不读取开发／正式数据，不覆盖既有目录。若测试端口被占用就报错退出，不换端口、不终止其他实例。

用浏览器打开终端给出的 URL。依次查看「总览」「趋势分析」「收入」「组合总览」「持仓与计划」，再从宽基 ETF 示例进入「投资笔记」。趋势可选择本年度，截图等待图表完成渲染；保留测试标记，不遮盖缺失数据提示或改写界面数值。以 JPEG 保存整页或正常视口画面，使用 README 对应的六个固定文件名。

截图前核对 `/api/health` 的 `environment=test` 和本次随机数据目录。人工逐图检查文字清晰、图表完整、没有真实姓名、账务、私人路径或凭据。`source_check.py` 只允许这六个文件名、JPEG 格式且单张不超过 2 MiB；二进制检查无法证明图片不含隐私，不能代替人工复核。

按 Ctrl+C 停止本次实例，脚本会等待进程退出并清理本次临时账本。日志留在源码之外；公开提交仅包含图片、合成器、隔离测试和本说明。合成历史覆盖运行时上年年初至当天，以便展示月度与年度相邻期比较；重建图可能与仓库中图片日期不同。
