# 产品截图：数据来源与重建

作者：Leo · 2026.11.12（截图采集于 2026.11.12）

README 的 11 张截图来自实际前端。账本、价格、汇率、收入和笔记由 `scripts/showcase.py` 独立合成，研究序列使用该脚本与 `tests/research_fixtures.py`、`tests/waterlevel_fixtures.py` 的人工样本。组合和指数名称带「示例」，界面保留「开发环境」标记。研究序列的观测日期沿用合成样本的日期。真实证券代码及页面上的数据源名称用于展示界面，图中数值均为合成。

图片位于 `docs/images/`，涵盖资产总览、趋势分析、收入与开支、组合收益首页、组合详情、持仓标的、持仓分析、投资笔记、指数研究首页、指数观察台和股票估值页的市场活动。合成器只在重建截图时显式运行，首次安装使用空账本。

## 重新生成

在已安装开发依赖的源码目录执行：

```sh
npm --prefix frontend run build
.venv/bin/python scripts/showcase.py
```

脚本在源码之外的 `local/work/showcase/` 下新建随机临时目录，以开发模式在临时回环端口运行并关闭同步。脚本只使用自己创建的合成账本。若端口发生占用，报错退出。

用浏览器打开终端给出的 URL，依次访问资产分析的「总览」「趋势分析」「收入/开支」。在「组合收益」先截组合列表，再点击「长期投资 · 示例」进入详情。随后查看「持仓标的」「持仓分析 → 配置进度」及宽基 ETF 示例的「投资笔记」。在「指数研究」先截全部估值分组列表，再进入「中证500 · 示例」观察台。最后在「市场水位 → 股票估值」滚动到两融余额及成交额。等待图表渲染，保留环境标记和数据状态。以 JPEG 保存浏览器视口画面，使用 README 中对应的文件名。

截图前核对 `/api/health` 的 `environment=dev`、`synthetic_fixture=true` 和终端输出的精确数据目录。保存后逐图打开核对文字、图表、环境标记与隐私边界。部分浏览器截图方式会漏掉 SVG 图表，遇到时改用原始视口截图并复核。`source_check.py` 校验白名单文件名、JPEG 格式和 2 MiB 单图上限。图片内容须逐张核验。

按 Ctrl+C 停止本次实例，脚本会等待进程退出并清理本次临时账本。日志留在源码之外；公开提交仅包含图片、合成器、隔离测试和本说明。合成历史覆盖运行时上年年初至当天，以便展示月度与年度相邻期比较；重建图可能与仓库中图片日期不同。
