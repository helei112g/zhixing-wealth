# 市场水位

Leo · 2026.11.06

「研究工具 → 市场水位」独立于指数资料库和投资组合。页面先计算可复核的历史相对位置，再给出规则摘要；不预测收益、不提供仓位指令。页面、AI事实包和离线报告使用同一版本结果。主页面默认截至当前日期，只从本地数据读取；5年、10年、全历史切换仅裁剪曲线，完整历史先参与均值计算。报告存档和下载位于「数据来源」的收起区域，不改变当前页面日期。

在「数据来源」手动更新单个来源或全部来源。市场数据不进入定时队列，旧自动设置停止生效，中断任务由用户重新发起。全市场估值首次采集或补充估值口径时按历史范围分片，后续从已有日期回溯30天，调用计入本机理杏仁基本面额度。组内全部口径校验通过后发布。历史乐咕快照与冻结报告保留原来源，当前视图使用理杏仁新序列。

「全历史」展示本地已取得的范围。市场指标保留各自实际观测日期，宏观按最新已发布月份显示，短历史对应的长期统计留空。

## 计算契约：waterlevel-v4

水位总览和股票估值各自提供 5 年、10 年、全历史按钮。债券与资金、宏观背景显示全历史，可在图内拖拽选择区间并恢复。

- 分位按原始日频或月频观测计算：严格小于当前值的有效样本数÷窗口有效样本数，当前观测计入分母；比较前统一到10位小数。需覆盖完整5/10年跨度且至少30点，跨度完整不表示没有缺日。优先10年，不足则5年，仍不足留空。
- 估值均值取最近60/120个完整自然月的最后观测，不含当前未完成月；缺月、月末无效值均使该窗口均值留空，不前填。偏离比例=当前值÷均值−1。这与指数资料库的3/5/10自然年日频均值、含半数相等值的分位口径不同。
- 图形按月末抽样，当月显示最新观测；分位使用原始序列，不用图形抽样计算。非正PE/PB显示原值及无效状态，不用旧正值、另一方法或另一来源替代。
- 股票固定使用沪深300/500/1000的mcw PE、300/500的mcw PB，以及理杏仁 A股全指中位数PE/PB两项。有效项取中位数，覆盖显示为有效数/7；三种估值方法是对照视角，不重复计分。
- 利率债为中国10Y国债收益率分位的反向值；信用债为AAA 3Y信用利差分位的反向值。综合为三个有效大类分数的中位数。缺类时覆盖组成改变，不能把不同覆盖版本当作同一完整指数。
- 水位0–100越高表示历史相对越贵；小于20/40/60/80依次分为极低/偏低/中性/偏高，其余极高。日频超过14个自然日、月频超过80日标记陈旧；缺失、无效、陈旧、相关来源更新失败的评分项不计分。来源未公布最新月份时的实时发布日期判断不等于这项宽松陈旧阈值。
- 利率/宏观同比单位为%，期限利差与M2−M1为百分点，回购及信用利差为BP（1个百分点=100 BP）。API中的分位、均值偏离、股息率为比例；页面股息率显示%。

## 版本、迁移与验收

schema11→12只新增空的market_snapshots、market_heads、market_reports、market_settings四表，不改既有账本、研究修订及笔记。来源发布递增研究revision，设置保存核对设置revision；两者都不递增账本revision。冻结核对原analysis_id与research_revision，保存不可变的结果、来源ID及方法版本；报告最近50条可列出，已知ID仍可回读。报告和来源随现有完整ZIP备份，恢复验证压缩摘要和引用。v4增加正数等权，v1/v2/v3冻结报告仍可读取、导出、备份和恢复。400MiB容量保护同样适用于新增市场来源与报告。

自动回归使用合成历史和替换后的供应商适配器，覆盖日期、缺口、同日差值、负估值、固定评分、手动任务、版本冲突、备份/迁移及浏览器真实渲染。公开来源只读连通性测试与合成回归分开报告；真实开发环境采集与自动回归分别记录；不据此声称已验证正式运行或生产迁移。相关入口：`tests/test_waterlevel.py`、`scripts/browser_waterlevel.cjs`、包含empty场景的`python scripts/verify.py --browser`。

接口与操作见[API](api.md)、[AI指南](ai.md)、[运行说明](operations.md)。新功能随PR审阅，合并与正式部署需独立授权。
